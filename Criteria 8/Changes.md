# Some Changes that were made during development due to issues noticed in the development stages
- UI system went under many tweaks and changes to make it more user friendly and easier to navigate.
- UI systems were written to limit user inputs allowing for fewer edge cases and bugs.
- Limiting User inputs also allowed for a more user friendly experience. and less edge cases for develops to have to account for
- During Development I ran into a few issues I had failed to document in my progress log 
- In the case of an unexpected crash, the game will not do anything to recover, but it will log errors to the console for debugging purposes.
- My UI Layout had changed from the original mockup due to time constraints and technical limitations in my ui system, I had originaly planned to have a more complex layout with more options and settings
  I had originally planed to have a more complex and stylised layout with more options and settings but due to time constraints and technical limitations in my ui system,
  I had to simplify the layout to ensure the core functionality was preserved, although I was able to keep the coloring scheme and general theme
- During Development I made used very generic colors for the UI but then later changed then to a more appealing color scheme
  
- The Ui did have a issues where under certain aspect rations and resolutions the ui would not scale correctly and some elements would be out of place, 
  this was partialy fixed by adding a ui scale option (which I intended to add regardless) to the settings menu allowing users to adjust the ui scale to their liking,
  this could be fixed further with more time by reworking the ui layout system.
